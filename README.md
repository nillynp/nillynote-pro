## Δυνατότητες (Απλό όπως το Windows 11 Notepad — Εξελιγμένο σε Pro)

- **Αυθεντικό καθαρό Windows 11 Interface με Καρτέλες:**
  - **Dark & Light Mode** με 1 κλικ + αυτόματο **Dark Titlebar** στα Windows 10/11.
  - Καθαρές καρτέλες με ένδειξη αλλαγών (`●`), κλείσιμο με μεσαίο κλικ, `+` για νέα καρτέλα (`Ctrl+N`) και δεξί κλικ μενού (αντιγραφή διαδρομής, άνοιγμα φακέλου, κλείσιμο άλλων).
  - **Single-Instance Multi-Tab:** Κάθε `.txt` που ανοίγεις από τον Explorer ανοίγει αμέσως ως νέα καρτέλα στο ίδιο παράθυρο (+ Drag & Drop).
- **Αυτόματη Επαναφορά Συνεδρίας:**
  - Αποθηκεύει αυτόματα τη συνεδρία και τις πρόχειρες σημειώσεις (drafts), ώστε να μπορείς να τις επαναφέρεις όταν ανοίξεις ξανά την εφαρμογή.
- **Pro Παραγωγικότητα χωρίς φόρτωμα UI:**
  - **100-step Multi-Level Undo / Redo** (`Ctrl+Z` / `Ctrl+Y`) + σωστό **`Ctrl+Backspace`** διαγραφής λέξης.
  - **Inline Find & Replace (`Ctrl+F` / `Ctrl+H`)** με μετρητή αποτελεσμάτων, Case-Sensitive (`Aa`) & **Regex (`.*`)**.
  - **Καρφίτσωμα επάνω — Always on Top (`Ctrl+T`)** & **Διαφάνεια παραθύρου (`100%` / `90%` / `80%`)**.
  - **Live Status Bar:** Θέση (`Γρ, Στ` με κλικ για `Ctrl+G`), **Λέξεις · Χαρακτήρες · Γραμμές** (και για επιλογή!), Zoom (`Ctrl + Ροδέλα`), εναλλαγή `CRLF`/`LF` και `UTF-8`/`Win-1253`.
  - **Μενού «Εργαλεία Pro»:** Ημερομηνία/Ώρα (`F5`), **Checklist `☐`/`☑` (`Ctrl+L`)**, Ταξινόμηση Α→Ω / Ω→Α, Αφαίρεση Διπλότυπων, Αφαίρεση Κενών, Trim, ΚΕΦΑΛΑΙΑ/πεζά, **Ελληνικά → Greeklish**, **SEO Slug**, **JSON Format/Minify**, **Quick Diff** (σύγκριση 2 καρτελών), **Άνοιγμα Link / Αναζήτηση Google** & Εκτύπωση (`Ctrl+P`).
  - **Πλήρης αυτόματη ανίχνευση Ελληνικών:** `UTF-8`, `UTF-8 BOM`, `UTF-16` και παλιά ελληνικά `Windows-1253` χωρίς ποτέ αλαμπουρνέζικα.

## Εγκατάσταση σε ΟΠΟΙΟΔΗΠΟΤΕ Windows 10/11 PC (100% Portable · Χωρίς Admin)

1. Κατέβασε το **`NillyNote-Pro-v1.0-Portable.zip`** και αποσυμπίεσέ το όπου θες (π.χ. `C:\Tools\NillyNotePro`).
2. Τρέξε με διπλό κλικ το **`Install_NillyNotePro.bat`** *(δεν απαιτεί δικαιώματα Administrator!)*.
   - Μεταγλωττίζει αυτόματα το 100% native **`NillyNotePro.exe` (~74 KB)** με τον ενσωματωμένο `.NET` compiler των Windows (0 εξωτερικά DLLs / 0 downloads).
   - Καταχωρίζει 16 τύπους αρχείων κειμένου ως επιλογές «Άνοιγμα με» (`.txt`, `.log`, `.md`, `.srt`, `.ini`, `.csv` κ.λπ.), δεξί κλικ Explorer και συντομεύσεις σε Desktop & Start Menu.

### Απεγκατάσταση
Τρέξε το **`Uninstall_NillyNotePro.bat`** — αφαιρεί καθαρά όλες τις εγγραφές και συντομεύσεις χωρίς να αγγίξει κανένα αρχείο σου.
